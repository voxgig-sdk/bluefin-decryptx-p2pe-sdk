list

GET /devices

Operation ID: list-devices.

Authentication: basic token (basic).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | partner | query | string | No | Filter the list by Partner. The parameter value can be either a Partner ID or Name. | | client | query | string | No | Filter the list by Client. The parameter value can be either a Client ID or Name. | | kif | query | string | No | Filter the list by KIF. The parameter value can be either a KIF ID or Name. | | serialNumber | query | string | No | Filter the list by a comma separated list of serial numbers. | | deviceState | query | enum: new, injected, inTransit, damaged, retired, destroyed, ... | No | Filter the list by Device State. | | take | query | integer (int32) | No | The number of entries to include in the list. | | skip | query | integer (int32) | No | The number of results to skip before listing entries. | | sorting.field | query | enum: id, version, created, modified, serialnumber, alternatekey, ... | No | The field to order the Device list. | | sorting.direction | query | enum: asc, desc | No | The direction to sort the Device list. |
